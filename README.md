#  Dotfiles(NixOs)

My personal dotfiles and configs for a minimal, fast, and customized Linux setup.  
Mostly config are declared or in progess. 
This repository contains configurations for both **bspwm** and **Hyprland**, along with my daily driver tools.

## ✨ Features

- **Window Managers**: bspwm, Hyprland
- **Terminal Emulators**: Foot, Kitty
- **Editor**: Neovim (with plugins and custom mappings) & Zed
- **Status Bar**: Waybar (for Hyprland), polybar(for i3)
- **App Launcher**: Rofi (with custom theme)
- **System Info**: Fastfetch
- **Multiplexer**: Tmux (custom keybinds & theme)


##  System

- OS: NixOs
- WM/DE: Hyprland & bspwm
- Shell: fish
- GPU: NVIDIA
- RAM: 16G
